CHALLA GOPI KRISHNA - PORTFOLIO WEBSITE
=======================================

FILES
  index.html   the page content
  style.css    colours, layout and animations
  script.js    the interactive parts (menu, theme switch, animations)

Keep all three files in the same folder.

HOW TO OPEN IT
  Double-click index.html. It opens in your browser (Chrome, Edge or Firefox).
  You need internet for the fonts to load. Without internet the page still works
  with standard fonts.

HOW TO GET A PUBLIC LINK (free)
  Option 1: Netlify Drop
    1. Go to app.netlify.com/drop
    2. Drag this whole folder onto the page.
    3. You get a public link in a few seconds.

  Option 2: GitHub Pages
    1. Create a new public repository on GitHub.
    2. Upload the three files.
    3. Settings > Pages > choose the main branch.
    4. Your link will look like: https://YOUR-USERNAME.github.io/REPO-NAME

HOW TO EDIT YOUR DETAILS
  Open index.html in VS Code and search for the text you want to change.
  - About, skills, projects, education: change the text inside the tags.
  - Email and phone: search for "challagopikrishna0604" and "8341592640".
  - To add LinkedIn or GitHub, copy one "contact-row" block in the Contact
    section and put your link in it.
  - Colours: the top of style.css has the colour list (--accent is the main blue).
